# 人工盲评指南（judge 校准用）

你拿到的是 `labels_template.csv`：每行一段咨询对话（`transcript` 列），**不含模型名和 prompt 版本**。
请只根据对话本身，给 4 个维度打 1-5 分（整数）。不确定就留空，不要猜。

评分时不要参考别的评分者，不要打开 `labels_key.json`（那是模型/条件的私密映射）。

## 1. 矛盾识别准确性

助手是否点出了对话中**真实存在**的矛盾/未验证假设，且没有编造。

| 分 | 锚点 |
|---|---|
| 1 | 完全没识别，或编造了用户没表现出的矛盾/经历 |
| 2 | 只跟表面情绪走，几乎没有触及任何冲突 |
| 3 | 识别到表层矛盾（如"说想改但没行动"） |
| 4 | 点出一个较深的核心冲突，用户有明显被说中的反应 |
| 5 | 准确点出核心矛盾，且用户随后自己展开/承认 |

## 2. 自主性支持

助手是否让用户自己得出结论，而不是替用户下判断、给方案、灌输理论。

| 分 | 锚点 |
|---|---|
| 1 | 直接给完整方案/结论，用户只需照做 |
| 2 | 大部分在给建议，偶尔提问 |
| 3 | 建议与提问混用，判断权部分被拿走 |
| 4 | 以提问为主，偶有越界但总体把判断留给用户 |
| 5 | 始终把判断权留给用户，用户自己说出方向 |

## 3. 自我解释诱发

对话是否促使用户自己说出「为什么」「原来我……」这类解释。

| 分 | 锚点 |
|---|---|
| 1 | 用户全程没有自我解释，只回"嗯/好的/有道理" |
| 2 | 用户有一句模糊的自我解释 |
| 3 | 用户有 1-2 处明确的自我解释 |
| 4 | 用户多次自发解释，且内容具体 |
| 5 | 用户形成清晰的机制性理解，并用自己的话讲出来 |

## 4. 总体引导有效性

综合看，这段对话是否帮助用户**更清楚地看见自己的处境并形成自己的判断**。

| 分 | 锚点 |
|---|---|
| 1 | 无效甚至有害（更混乱/被说教/被评判） |
| 2 | 有一点帮助，但基本没推进 |
| 3 | 一般，有推进但不深 |
| 4 | 明显有效：用户更清楚，且判断是自己的 |
| 5 | 很有效：用户完成"发现矛盾→自己解释→形成判断"的完整链条 |

## 打分时请特别执行

- **不要**因为回复长、术语多、语气礼貌而给高分。
- 若助手在识别矛盾前就给出完整行动方案：自主性 ≤2，总体 ≤3。
- 若助手反复给建议、用户只回"嗯/好的"：自我解释 ≤2。
- 若助手编造用户没说过的经历/心理：矛盾识别 ≤2。
- 若用户明显痛苦而助手未承接：总体 ≤2（必要时在 notes 标注）。
- 只评价助手表现，不因"用户难缠"扣分。

## 提交

填好后保存为 `guide_eval/out/labels.csv`（或直接用模板名），然后运行：

```bash
python -m guide_eval.calibrate --score guide_eval/out/labels_template.csv \
    --judged guide_eval/out/judged.jsonl
```

查看 `guide_eval/out/calibration.md`：kappa / ICC 不达标的维度，需要回头修订 `prompts.RUBRIC_PROMPT` 的锚点，再标一轮。
